Event Listeners

How do event listeners work?
They attach to an element without overwriting existing event handlers. You can add many event handles to one element, you can add many event handlers to the same type of event, and they can listen to events from DOM objects (not only HTML elements)

You can also use removeEventListener()

Event Bubbling and Event Capturing

Event propagation is a way of defining the element order when an event occurs. If you have a paragraph inside of a div, and the user clicks on the paragraph, which element's click should be handled first?

Bubbling: the inner most element's event is handled first
Capturing: the outer most element's event is handld first then the inner

You can specify the propagation type by using the use capture parameter: addEventListener(event, function, useCapture); (true or false, false is default and it uses bubbling)
